# متتبع ليمت Claude

تطبيق ويب (PWA) قابل للتثبيت على أندرويد لتتبع حسابات Claude ومشاريعها وأوقات انتهاء الليمت.

## المميزات
- عدد غير محدود من الحسابات، ولكل حساب قائمة مشاريع.
- زر «وصلت الليمت الآن» يسجل وقت الانتهاء تلقائيا (الانتظار الافتراضي 5 ساعات، وقابل للتعديل لكل حساب)، ويمكن تعديل وقت الانتهاء يدويا.
- عداد تنازلي دائري لكل حساب.
- إشعار عند جاهزية الحساب مع أسماء مشاريعه، وشارة رقمية على أيقونة التطبيق بعدد المشاريع الجاهزة.
- يعمل بدون إنترنت، والبيانات محفوظة على جهازك فقط.

## النشر على GitHub
1. أنشئ مستودعا جديدا وارفع كل الملفات إلى فرع `main`.
2. من **Settings ← Pages** اختر **Source: GitHub Actions**.
3. عند كل push يشغّل الـ workflow الاختبارات ثم البناء ثم النشر، ويظهر الرابط في تبويب Actions.

## التثبيت على أندرويد
افتح الرابط في Chrome ← القائمة ← **تثبيت التطبيق** (Add to Home screen). ثم فعّل الإشعارات من داخل التطبيق.
لتحويله إلى APK يمكنك استخدام [PWABuilder](https://www.pwabuilder.com) بإدخال رابط الصفحة.

## التطوير
```
npm test        # الاختبارات (لا توجد حزم خارجية)
npm run build   # يبني مجلد dist
```

## ملاحظة عن الإشعارات
الإشعار الدقيق بالثانية يعمل والتطبيق مفتوح أو في الخلفية القريبة. عند إغلاقه تماما يعتمد أندرويد على «المزامنة الدورية» (تقريبا كل 15 دقيقة أو أكثر حسب استخدامك للتطبيق)، ولا يمكن ضمان توقيت أدق دون خادم إشعارات أو تطبيق أصلي.
