# متتبع ليمت Claude 📱

تطبيق أندرويد أصلي (APK) لتتبع حسابات Claude ومشاريعها وأوقات انتهاء الليمت.
مبني بـ **Capacitor** — يعمل بدون إنترنت، ويرسل إشعارات أصلية حقيقية حتى لو التطبيق مغلق.

---

## كيف تحصل على APK

### الطريقة السهلة — GitHub Actions (موصى بها)

1. ارفع المستودع على GitHub (فرع `main`).
2. من **Settings → Pages** لا تحتاج شيئاً — الـ workflow يبني APK تلقائيا.
3. اذهب إلى تبويب **Actions** → اضغط على أحدث workflow → حمّل الـ `claude-limits-apk`.
4. **أو**: كل push على `main` ينشئ **GitHub Release** مباشرة، حمّل APK من تبويب **Releases**.

### الطريقة اليدوية (تحتاج Android Studio)

```bash
npm install
npm run build:web          # يبني dist/
npx cap add android        # مرة واحدة فقط
npx cap sync android       # في كل تغيير
npx cap open android       # يفتح Android Studio
# Build → Generate Signed APK
```

---

## التثبيت على أندرويد

1. حمّل `claude-limits.apk`
2. اذهب إلى **الإعدادات → الأمان → مصادر غير معروفة** وفعّلها (أو عند مطالبتك)
3. افتح الملف وثبّته
4. افتح التطبيق ← اسمح بالإشعارات عند السؤال

## المميزات

| الميزة | التفاصيل |
|--------|----------|
| 🏦 حسابات متعددة | أضف كل حساباتك على Claude |
| 📁 مشاريع لكل حساب | سجّل اسم كل مشروع تعمل عليه |
| ⏳ تتبع الليمت | زر «وصلت الليمت الآن» يبدأ العد التنازلي |
| 🔔 إشعارات أصلية | إشعار مجدوَل تلقائيا عند انتهاء وقت الانتظار، **حتى لو التطبيق مغلق** |
| 🕐 عداد دائري | يعرض الوقت المتبقي بصريا لكل حساب |
| ✏️ تعديل يدوي | تغيير وقت الانتهاء أو ساعات الانتظار لكل حساب |
| 💾 بيانات محلية | لا سيرفر، البيانات محفوظة على جهازك فقط |
| 📴 بدون إنترنت | يعمل بالكامل offline |

## بنية المشروع

```
├── src/                   # كود الواجهة
│   ├── core.js            # منطق التطبيق (لا DOM) — يُختبر مع Node
│   ├── store.js           # تخزين IndexedDB (للمتصفح)
│   ├── app.js             # واجهة المستخدم + Capacitor APIs
│   ├── index.html
│   ├── style.css
│   └── icons/
├── test/
│   ├── core.test.js       # 12 اختبار للمنطق
│   └── build.test.js      # 8 اختبارات للبناء
├── scripts/build.js       # يبني dist/
├── capacitor.config.json  # إعدادات Capacitor
├── .github/workflows/
│   └── ci-deploy.yml      # اختبار → بناء APK → GitHub Release
└── android/               # يُولَّد تلقائيا بـ `cap add android`
```

## ملاحظة عن الإشعارات

الإشعارات **مجدولة مسبقاً** على أندرويد عبر `LocalNotifications` من Capacitor — تماماً مثل تطبيقات التنبيه الأصلية. تصل في الوقت المحدد حتى لو التطبيق مغلق تماماً.
